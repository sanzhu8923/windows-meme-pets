# Windows 桌宠移植

把 Ganzhe2028 的 SunPet、ShaolanPet 和 FengGe-Desktop-Pet 移植为 Windows 可双击运行的三个独立程序。保留原头像与 76 段原声，点击播放、拖动、透明置顶、右键菜单、音量、大小、随机不重复、固定台词、句子筛选、位置记忆及有限接话链。

实现选择：Windows 自带 .NET Framework 4.x + WPF，直接用系统编译器构建，不要求用户安装 Python、Node 或开发工具。Electron 与 Python 会增加运行时体积；此处使用原生 WPF 透明窗口。角色共用一份实现，按 exe 名称选择素材。移植代码放在新目录，不改上游 Swift 仓库。

接话使用本机窗口消息与每角色命名互斥体；不建立网络连接。薄肌→太对了→好事→太对了，最多三跳；好事→太对了一跳。没有后台自动发声。窗口不抢输入焦点，托盘菜单可以找回、停止、退出全部。

Mac 机身传感器不移植；Windows 单击或双击均触发说话。保留原始素材许可与来源；这是本地非官方移植。设置存在当前用户 LocalAppData，不需要管理员权限。绿色包包含 assets，不能单独搬走 exe。

验证：核心规则测试（随机轮播、筛选、固定选择回退、防环、位置恢复）；76 段音频逐一通过 Windows 解码器打开；三个进程实测接话链、停止和关闭、单实例；查看 Windows 实际透明窗口与右键菜单。程序诊断写入独立测试目录，常规运行不记录内容。
